## ① 앞 인트로 (신규 제작 · 약 10~12초, 파트 A 앞)

**목적:** 문제 → 약속 → 3파트 구조를 10초 안에.

**비주얼:** 다크 네이비. TREASURER 워드마크가 중앙 → 상단으로 안착. 키워드 3개가 순차 등장 후 흩어진 카드들이 하나의 라인으로 정렬되는 모션.

**나레이션(안):**
> "재보험 정산은 SOC·보더로·인보이스가 이메일과 엑셀에 흩어진 채, 사람 손으로 대사됩니다.
> 물량은 늘지만, 사람을 무한정 늘릴 수는 없습니다.
> TREASURER 재보험 정산 AI는 이 업무를 '통제 가능하게' 만듭니다."

**화면 자막(키워드 3):** `흩어진 정산 근거` → `늘어나는 물량` → `한정된 인력`
**마무리 자막:** `통제한다 → AI가 만들고 사람이 승인한다 → 운영하고 개선한다`
**강조:** 마지막 문장에서 3개 파트 제목을 블루로 점등, 그대로 파트 A로 wipe.

## 파트 A — "문제를 통제한다" (35s)
> **파트 타이틀 카드(신규):** `PART A · 문제를 통제한다` / 부제 `업무량과 위험을 한 화면에서` (2s)

### S1 · 통합 관제 대시보드 (Overview) — ≈0:00–0:13
- **기능 인트로 카드:** `① 통합 관제 대시보드` / `이번 달 정산 업무량과 리스크를 한 화면에`
- **나레이션:** "먼저, 이번 달 업무 전체를 한 화면에서 봅니다. 처리 계정 48건, 그중 불일치 6건, 미입금 3.4억."
- **강조 연출:**
  - `≈0:00.5–0:02` KPI 4개 카운트업 구간 — 카운터 상승 사운드. **불일치 6건(빨강 + ACTION 배지)** 에 하이라이트 박스 + 살짝 푸시인.
  - `≈0:02–0:04` RISK ALERTS 4행 슬라이드인 — 최상단 `SOC-2026-0417 한도 초과 ₩12.4M` 에 콜아웃 "즉시 확인 대상".
  - 우측 SETTLEMENT FUNNEL: 발송 단계(블루 바)만 스포트라이트.

### S2 · 계정별 대사 (Claims by Account) — ≈0:13–0:25
- **기능 인트로 카드:** `② 계정별 자동 대사` / `SOC와 원장을 비교, 차이 있는 계정만`
- **나레이션:** "SOC와 우리 원장을 자동 대사합니다. 48건 전체가 아니라, 차이가 있는 6건만 남깁니다."
- **강조 연출 (이 씬의 핵심):**
  - `≈0:16.2` **"차이 있는 건만" 토글이 켜지는 순간** — 토글에 클릭 사운드 + 원형 리플. 여기서 0.3s 홀드.
  - `≈0:16.5–0:17.5` 48 → 6 필터링(일치 행이 접힘). 사라지는 행은 살짝 페이드, **남는 6행의 DIFF 컬럼(빨강)** 에 하이라이트.
  - 상단 카운트 `48건 → 6건` 숫자 변화에 콜아웃 "42건 자동 일치".

### S3 · 데이터 전수 검사 (Data Audit) — ≈0:25–0:35
- **기능 인트로 카드:** `③ 예외 전수 검사` / `샘플링이 아니라 전 건, 예외만 집중`
- **나레이션:** "샘플링이 아닙니다. 1만 2천 4백 행 전수 검사 후, 예외 30건에만 집중합니다."
- **강조 연출:**
  - `≈0:25.7–0:27.7` **12,400 카운터 + 100% 진행바** — 상승 사운드, 100% 도달 순간 프리즈 0.5s + "전수 검사" 라벨 점등.
  - 우측 상단 **예외 30건(빨강)** 푸시인.
  - `≈0:29 / 0:30.8` 정체/미입금/미검수 탭 전환 — 탭 넘어갈 때 가벼운 틱.

## 파트 B — "AI가 만들고, 사람이 승인한다" (40s)
> **파트 타이틀 카드:** `PART B · AI가 만들고, 사람이 승인한다` / `기존 파일·이메일을 버리지 않습니다` (2s)

### S4 · 근거 체인 (Documents) — ≈0:00–0:12
- **기능 인트로 카드:** `④ 근거 체인` / `Treaty → BDX → SOC → Invoice를 하나로`
- **나레이션:** "흩어진 문서를 버리지 않습니다. 특약부터 인보이스까지 하나의 근거 체인으로 연결합니다."
- **강조 연출:**
  - `≈0:00.6–0:03` 4개 노드가 순차 등장하고 **연결선이 왼→오로 그려지는 모션** — 선이 이어질 때 "슉" 사운드. 각 노드 등장 시 ID(TRY/BDX/SOC/INV) 살짝 강조.
  - 마지막 **INVOICE 노드(블루)** 도착 시 글로우 + "원문 추적 가능" 콜아웃.

### S5 · 슬립 자동 초안 (Slip Generator) — ≈0:12–0:28  ★영상의 하이라이트
- **기능 인트로 카드:** `⑤ AI 슬립 초안` / `이메일·엑셀에서 추출해 초안 자동 생성`
- **나레이션:** "받은 이메일과 엑셀에서 필요한 값을 AI가 추출합니다. 각 필드가 어디서 왔는지 출처까지 함께 남깁니다."
- **강조 연출:**
  - `≈0:14.3` 좌측 이메일 원문에서 **요율 4.85% / 수수료 15% / 한도 20M / 지분 35%** 하이라이트되는 순간 — 해당 라인에 노란/블루 형광 스윕.
  - `≈0:14.3–0:21.6` 우측 RQ Slip 필드가 하나씩 채워짐 — 필드마다 짧은 틱, **출처 배지(파랑=이메일 / 초록=엑셀)** 팝 등장에 미세 확대.
  - 연출 팁: 좌(이메일 근거) → 우(채워지는 필드)로 시선을 잇는 라인/화살 강조를 한 번만.
  - 마지막 필드까지 채워지면 0.5s 홀드 + "8개 필드 자동 추출" 콜아웃.

### S6 · 검수 큐 & 감사 로그 (RQ Slip) — ≈0:28–0:40
- **기능 인트로 카드:** `⑥ 사람 검수 + 감사 이력` / `AI 초안은 바로 발송되지 않습니다`
- **나레이션:** "AI 결과는 바로 나가지 않습니다. 사람이 검수·수정하고, 그 이력이 전부 남습니다."
- **강조 연출:**
  - `≈0:28–0:30` 좌측 diff — **수정된 2개 필드(Brokerage 12.5%→15.0%, 지분 30%→35%)** 강조. AI값(취소선)→수정본(초록)으로 시선.
  - `≈0:33` **APPROVE 버튼 클릭 → APPROVED(초록)로 전환** 순간 — 확정음 + 버튼 살짝 눌림. 여기 프리즈 0.4s.
  - 우측 AUDIT LOG 타임라인 `ARIA 생성 → 김서연 수정 → 박준호 승인` — 승인 노드 찍히는 순간 콜아웃 "누가·언제·무엇을 (불변 기록)".
