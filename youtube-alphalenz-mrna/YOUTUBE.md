## 재제작 방법

전체 파이프라인은 README.md, 녹음은 RECORDING.md 참고.

```bash
npm install
node scripts/tts.mjs          # 나레이션 + timing.json + srt (대본 수정 시)
node scripts/capture.mjs      # alpha-lenz.com 제품 화면 캡처
npx remotion render src/index.ts Main out/video-silent.mp4 --concurrency=4
node scripts/mux.mjs          # 나레이션(+ bgm/ 폴더에 음원 있으면 자동 믹스) 합성
```

- 대본: `src/script.json` (`vo` = 나레이션 원고, `sub` = 화면 자막)
- BGM: `bgm/` 폴더에 mp3/wav를 넣고 `node scripts/mux.mjs`만 다시 실행하면
  -24dB + 사이드체인 덕킹으로 나레이션 밑에 깔립니다. 영상 재렌더 불필요.
- 보이스/속도 교체: `VOICE=ko-KR-SunHiNeural RATE=+14% node scripts/tts.mjs`
  (현재: ko-KR-HyunsuMultilingualNeural · +16% · 약 5.2음절/초)
