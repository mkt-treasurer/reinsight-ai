# 나레이션 만들기 (클로바더빙)

대본은 **구어체**로 다시 썼습니다. 전 23문장.

- `클로바더빙-대본.txt` — 문장별 번호·파일명이 붙은 전체 대본
- `클로바더빙-문장만.txt` — 문장만 23줄. 복붙용

## 1. 클로바더빙에서 뽑기

https://clovadubbing.naver.com

1. 새 프로젝트 → 영상 없이 오디오만 만들어도 됩니다
2. `클로바더빙-문장만.txt` 의 문장을 **한 줄에 하나씩** 더빙으로 추가
3. 목소리는 **차분한 남성/여성 아나운서형** 말고 **일상 대화형**을 고르세요.
   대본이 "~에요 / ~거든요 / 근데" 톤이라 앵커 보이스를 얹으면 어색해집니다
4. 속도는 기본 또는 살짝 빠르게

### 내보내기 — 둘 중 아무거나

**A. 문장별 개별 파일** (가장 확실)
파일명을 `클로바더빙-대본.txt` 의 이름 그대로 붙여서 `audio/rec/` 에 넣으세요.
예: `s1-hook-01.mp3`, `s2-spread-01.mp3` …

**B. 전체 오디오 한 개**
`audio/rec/all.mp3` 로 넣으면 됩니다.
단, **문장 사이를 1초 이상 띄워서** 배치해 주세요. 이 무음으로 문장을 자동 분할합니다.
클로바더빙은 더빙마다 시작 시각을 지정할 수 있으니, 1.2초쯤 간격을 두면 안전합니다.

## 2. 넣고 실행

```bash
cd youtube-alphalenz-mrna && node scripts/import-recording.mjs
```

레벨 정리(-18 LUFS)를 하고 문장별 길이를 표로 보여줍니다.
`확인` 표시가 붙은 줄은 잘못 잘렸을 수 있으니 그 문장만 다시 넣고 재실행하면 됩니다.

그 다음 영상 렌더는 제가 돌립니다. 자막과 모션이 새 오디오 길이에 맞춰 다시 계산됩니다.

## 3. 직접 녹음하실 경우

같은 방식입니다. `audio/rec/` 에 넣고 같은 명령을 돌리면 됩니다.
휴대폰 음성메모로 충분하고, 입에서 15~20cm 비스듬히, 문장 사이 1초 이상 쉬어주세요.
카펫 깔린 방이나 커튼 친 방이 좋고 화장실·주방은 울려서 최악입니다.
